# Terminal & Git Rules

- **Allowed Git & Dev Commands**:
  - `git status` (Read-only status check)
  - `git remote -v` (Read-only remote list)
  - `npm run dev` (Start / manage development server)
  - Build/test validation commands when needed.

- **Strictly Prohibited Actions**:
  - **NEVER** run `git push` automatically under any circumstances.
  - Do **NOT** run `git add`, `git commit`, or `git push` on your own.
  - The USER will handle all git staging, committing, and pushing manually.
