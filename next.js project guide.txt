1. MIGRATION OVERVIEW (প্রজেক্ট মাইগ্রেশন ও আর্কিটেকচার ওভারভিউ)
-------------------------------------------------------------------------------

* পুরাতন স্ট্যাক (Old Architecture):
  - Frontend: Plain HTML, CSS, Vanilla JavaScript
  - Backend: Node.js (Express.js) deployed on Render (Multiple Render Services)
  - Database: MongoDB Atlas (Mongoose ORM / Multi-database cluster)
  - Email Service: Brevo (Password Reset System)

* নতুন স্ট্যাক (New Architecture):
  - Frontend Framework: Next.js 14 (App Router Architecture) & React 18
  - Styling: Pure CSS & Modern Responsive Design (`src/app/globals.css`)
  - Backend Engine: Next.js API Route Handlers (`src/app/api/`) + Cloudflare Pages Serverless Edge Functions (`functions/`)
  - Hosting: Cloudflare Pages (`https://topmcqbd.pages.dev`)
  - Database Driver: Official Native MongoDB Node.js Driver (`MongoClient`) using `nodejs_compat` + Mongoose Models for local dev
  - Email Gateway: Brevo (Sendinblue) Transactional REST API
