-------------------------------------------------------------------------------
1. PROJECT ARCHITECTURE OVERVIEW (প্রজেক্ট আর্কিটেকচার ওভারভিউ)
-------------------------------------------------------------------------------

* Frontend & CDN/DNS: Cloudflare (Cloudflare Pages & Cloudflare DNS / CDN)
* Backend API Services: 2x Render Web Services (Full Node.js Runtime - No Edge/Function Restrictions)
* Database Layer: 2x MongoDB Atlas Clusters (Paid & Free Dedicated Clusters)
* Dual Render + Dual MongoDB System:
  - 1st Render Service (Main/Paid) -> Connected to Paid MongoDB (TopMCQBD_DB)
  - 2nd Render Service (Free MCQ)  -> Connected to Free MongoDB (TopMCQBD_DB_Free)
* Framework: Next.js (App Router Architecture) / Node.js
* Styling: Tailwind CSS & Global CSS (`src/app/globals.css`)
* Database Driver: Native MongoDB Node.js Driver (`MongoClient`) & Mongoose
* Email Gateway: Brevo API Integration for Password Reset & System Notifications
