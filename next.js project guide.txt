1. PROJECT ARCHITECTURE OVERVIEW (প্রজেক্ট আর্কিটেকচার ওভারভিউ)
-------------------------------------------------------------------------------

* Framework: Next.js 14 (App Router Architecture)
* Language/Syntax: JavaScript (ES Modules, JSX)
* Styling: Vanilla CSS & Tailwind CSS (`src/app/globals.css`)
* Backend API: Next.js Route Handlers (`src/app/api/`) & Cloudflare Pages Functions (`functions/api/`)
* Deployment & Hosting: Cloudflare Pages (`npm run build:cloudflare`)
* Database Engine: MongoDB Atlas (M0 Free Tier Multi-Cluster Architecture)
* Dual Database Architecture:
  1. Primary Paid DB (TopMCQBD_DB) — ইউজার, অথেনটিকেশন, পেইড MCQ, সাবস্ক্রিপশন, ডায়নামিক কনফিগ
  2. Secondary Free DB (TopMCQBD_DB_Free) — উন্মুক্ত ফ্রি MCQ লাইব্রেরি ও প্র্যাকটিস ডাটা
* Email Gateway: Brevo (Sendinblue) REST API for Password Reset & System Notifications
* Authentication: JWT Token (HS256) + Bcrypt Password Hashing

4. MONGODB ATLAS DUAL DATABASE CONFIGURATION
===============================================================================

১. ডাটাবেজ আর্কিটেকচার:
   - Primary Database: `TopMCQBD_DB` (পেইড ইউজার, এডমিন, পেইড এমসিকিউ, সাইট সেটিংস)
   - Secondary Database: `TopMCQBD_DB_Free` (উন্মুক্ত ফ্রি এমসিকিউ ডাটাবেজ)

২. MongoDB Collections:
   1. `users` — ইউজার অ্যাকাউন্ট, পাসওয়ার্ড (bcrypt), রোল (owner, admin, customer), সাবস্ক্রিপশন প্ল্যান, পেমেন্ট রিকোয়েস্ট
   2. `questions` — এমসিকিউ প্রশ্নসমূহ, অপশনস, সঠিক উত্তর (ইনডেক্স), বিস্তারিত ব্যাখ্যা, ক্যাটেগরি
   3. `configs` / Config Collections — হোমপেজ ব্যানার, হেডার মেনু, ফুটার লিংকস, সাইডবার ও পলিসি কনফিগারেশন
