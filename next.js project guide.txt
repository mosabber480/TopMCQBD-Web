-------------------------------------------------------------------------------
1. MIGRATION OVERVIEW (প্রজেক্ট মাইগ্রেশন ওভারভিউ)
-------------------------------------------------------------------------------

* পুরাতন স্ট্যাক (Old Architecture):
  - Frontend: Plain HTML, CSS, Vanilla JavaScript
  - Backend: Node.js (Express.js) deployed on Render (Multiple Render Services)
  - Database: MongoDB Atlas (Mongoose ORM)
  - Email Service: Brevo (Password Reset)

* নতুন Next.js স্ট্যাক (New Architecture):
  - Framework: Next.js (App Router Architecture)
  - Language/Format: JSX / ES Modules (JavaScript)
  - Styling: Tailwind CSS / Global CSS (`src/app/globals.css`)
  - Backend API: Next.js API Route Handlers (`src/app/api/`)
  - Database Models: Mongoose Models (`src/models/`)
  - Utilities & Helpers: `src/lib/` (`db.js`, `auth.js`, `brevo.js`, `config.js`)
  - Email Service: Brevo API Integration
