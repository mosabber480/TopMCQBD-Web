1. MIGRATION OVERVIEW (প্রজেক্ট মাইগ্রেশন ও আর্কিটেকচার ওভারভিউ)
-------------------------------------------------------------------------------

* পুরাতন স্ট্যাক (Old Architecture):
  - Frontend: Plain HTML, CSS, Vanilla JavaScript
  - Backend: Node.js (Express.js) deployed on Render (Multiple Render Services)
  - Database: MongoDB Atlas (Mongoose ORM / Multi-database cluster)
  - Email Service: Brevo (Password Reset System)

* নতুন স্ট্যাক (New Architecture):
  - Frontend Framework: React.js (Vite) / Next.js (App Router Architecture)
  - Backend Engine: Cloudflare Pages Serverless Functions & Next.js Route Handlers (OpenNext Cloudflare)
  - Hosting & Scaling: Cloudflare Pages (Dual Account Setup for 2,00,000 Free Daily Requests)
  - Database Driver: Native MongoDB Node.js Driver (MongoClient) using `nodejs_compat`
  - Email Gateway: Brevo (Sendinblue) Transactional Email API

9. IMPORTANT: MONGODB DATABASE CONNECTION & VARIABLES GUIDE
===============================================================================

⚠️ MONGODB APP ID & KEY সংক্রান্ত তথ্য (কেন ব্যবহার করা হয়নি):
   - MongoDB Atlas তাদের পুরনো "Data API / App Services" সুবিধাটি Deprecate/বন্ধ করে দিয়েছে। 
   - নতুন তৈরি করা কোনো MongoDB ক্লাস্টারে এখন আর Data API App ID বা Data API Key জেনারেট করা যায় না।
   - সুতরাং, `MONGODB_APP_ID_PAID`, `MONGODB_API_KEY_PAID` বা HTTP HTTPS REST API URL (`services.cloud.mongodb.com`) প্রজেক্টে ব্যবহার করা হয়নি।

✅ প্রজেক্টে বর্তমানে যা ব্যবহৃত হচ্ছে (Native MongoDB Driver System):
   - প্রজেক্টের `package.json` থেকে অফিশিয়াল `mongodb` NPM ড্রাইভারে থাকা `MongoClient` ব্যবহার করে সরাসরি ডাটাবেসে কানেক্ট করা হয় (`npm install mongodb`)।
   - Cloudflare Pages Functions-এ Native Driver চালানোর জন্য `wrangler.toml` ফাইল ও ড্যাশবোর্ডে `compatibility_flags = ["nodejs_compat"]` এনাবল রাখা হয়েছে।
