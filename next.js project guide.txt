1. PROJECT ARCHITECTURE OVERVIEW (প্রজেক্ট আর্কিটেকচার ওভারভিউ)
-------------------------------------------------------------------------------

* Framework: Next.js (App Router Architecture)
* Language/Syntax: JavaScript (ES Modules, JSX)
* Styling: Tailwind CSS & Global CSS (`src/app/globals.css`)
* Backend API: Next.js Route Handlers (`src/app/api/`) & Cloudflare Pages Functions (`functions/api/`)
* Deployment & Hosting: Cloudflare Pages (`npm run build:cloudflare`)
* Database Engine: Cloudflare D1 (Native Serverless SQLite / Relational SQL) — 0ms Latency
* Dual Account System: 2 Cloudflare Accounts (100,000 + 100,000 = 200,000 Free Daily Requests)
* Database Binding: `DB` (Mapped to D1 Database `topmcqbd-db` via `wrangler.toml`)
* Email Gateway: Brevo API Integration for Password Reset & System Notifications
