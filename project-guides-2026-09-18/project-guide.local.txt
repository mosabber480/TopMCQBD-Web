1. PROJECT ARCHITECTURE OVERVIEW (প্রজেক্ট আর্কিটেকচার ওভারভিউ)
-------------------------------------------------------------------------------

* Frontend & Edge Layer: Cloudflare Pages + Cloudflare Functions + Cloudflare CDN
* Edge SQL Database: Cloudflare D1 Database (For Header, Footer, Announcements & Site Configs)
* High Concurrency Edge Caching: Optimized for 30,000+ Concurrent/Active Students (0ms Edge Response)
* Backend API Microservices Layer: 
  - 5x Paid Render Web Services (Dedicated High Performance Microservices)
  - 1x Free Render Web Service (High-Traffic Free Practice Engine)
* Sleep Mode Prevention: UptimeRobot 24/7 Keep-Alive Cron Monitor (5-minute HTTP Ping for all 6 Render services to eliminate cold starts)
* Database Layer: 6x MongoDB Atlas Clusters (5 Dedicated Paid Clusters + 1 Free Cluster)
* Microservices Distribution:
  1. 1st Render Service (Paid Core/Auth) -> Connected to `TopMCQBD_DB`
  2. 2nd Render Service (Subjective MCQs) -> Connected to `TopMCQBD_DB_Subjective`
  3. 3rd Render Service (Live Exam Engine) -> Connected to `TopMCQBD_DB_Live_Exam`
  4. 4th Render Service (Written Exam Engine) -> Connected to `TopMCQBD_DB_written`
  5. 5th Render Service (Question Bank Engine) -> Connected to `TopMCQBD_DB_Question_Bank`
  6. 6th Render Service (Free MCQ Engine) -> Connected to `TopMCQBD_DB_Free`
* Two-Way API Sync: Render APIs fetch live data from Cloudflare D1 and forward updates directly to D1.
* Framework: Next.js (App Router Architecture) / Node.js
* Database Drivers: Cloudflare D1 Driver (Binding `DB`) + Native MongoDB Node.js Driver / Mongoose
* Email Gateway: Brevo API Integration for Password Reset & System Notifications
* AI Assistant Layer: TopMCQBD AI Tutor Engine (`/api/ask-ai`) with Google Gemini Live Model + Built-in Smart Pedagogical Fallback (Zero Downtime / Quota-Proof).
