[!] বিশেষ নিয়মাবলি ও গুরুত্বপূর্ণ নির্দেশিকা:
১. এই পেজগুলো মূল ওয়েবসাইটের কোনো পাবলিক বা ভিজিটর পেজ নয়; এগুলো শুধুমাত্র সরাসরি ডেটাবেজ ও ক্লাউড সার্ভিস টেস্ট/যাচাই (Diagnostic) করার পেজ।
২. এই পেজগুলোতে কোনো অবস্থাতেই http://localhost:3000/ API বা লোকাল Node.js API ব্যবহার হবে না (এমনকি লোকালহোস্টে ব্রাউজ করলেও না)।
৩. প্রতিটি পেজ কেবল তার জন্য নির্ধারিত নির্দিষ্ট লাইভ ক্লাউড সার্ভিসের সাথে সরাসরি যোগাযোগ করে:
   • db-pages-api ও dbd1-api -> সরাসরি Cloudflare Pages Functions লাইভ API (https://topmcqbd.pages.dev)
   • db-workers-api -> সরাসরি Cloudflare Workers Backup লাইভ API (https://topmcqbd-backup-api.mosabber5266.workers.dev)
   • Render টেস্ট পেজসমূহ -> সরাসরি Render ডেডিকেটেড লাইভ মাইক্রোসার্ভিস (https://*.onrender.com)
